# CSV를 매출 시트로 이관

csv 폴더의 CSV를 파일명순으로 읽어 `매출.xlsx`의 매출 시트를 전체 교체하고, 성공한 파일만 `completed`로 옮기는 Python 프로그램 사양서입니다.

## Notes

- 실행 시 tkinter.filedialog로 경로를 고른다. 대화 상자 기본 경로는 `C:\`
  - CSV 원본 폴더: 폴더 선택 대화 상자
  - 매출.xlsx: 파일 선택 대화 상자
  - 선택을 취소하면 엑셀을 변경하지 않고 종료한다
- 대상 경로 (선택한 뒤)
  - CSV 입력: 선택한 폴더 바로 아래의 `.csv` (하위 폴더, 특히 `completed`는 읽지 않음)
  - 엑셀: 선택한 `매출.xlsx`의 `매출` 시트
  - 완료 이동: 선택한 CSV 폴더 안의 `completed` (없으면 생성)
- CSV 컬럼(헤더 그대로 사용): 매출일, 영업소, 영업담당, 기간, 전표번호, 상품코드, 상품명, 대분류, 중분류, 소분류, 거래처코드, 거래처명, 매출수량, 매출금액, 매출이익, 단가
- 처리 순서: 파일명 가나다순(정렬)
- 매출 시트: 기존 내용을 비운 뒤 CSV 합본으로 전체 교체. 다른 시트는 유지
- 매출.xlsx 또는 `매출` 시트가 없으면 오류로 중단 (파일 이동 없음, 엑셀 변경 없음)
- 개별 CSV 읽기 실패: 해당 파일은 csv 폴더에 남기고, 나머지 성공 파일만 엑셀에 반영
- 엑셀 저장 성공 후에만, 읽기에 성공한 CSV를 completed로 이동. 저장 실패 시 이동하지 않음
- completed에 같은 이름 파일이 있으면 덮어씀
- CSV가 하나도 없으면 엑셀을 변경하지 않고 종료
- Python은 프로젝트 `.venv`에서 실행. 생성한 `.py` 파일은 삭제하지 않음
- CSV 인코딩은 UTF-8을 우선 시도하고, 실패 시 CP949로 재시도
- 숫자 컬럼(매출수량, 매출금액, 매출이익, 단가)은 숫자로 기록

## 확정된 요구사항

1. 실행하면 CSV 원본 폴더와 `매출.xlsx`를 대화 상자로 고른다. 기본 경로는 `C:\`이다.
2. 선택한 csv 폴더(`completed` 제외)의 모든 CSV를 파일명 가나다순으로 읽는다.
3. 선택한 `매출.xlsx`의 `매출` 시트를 비우고, CSV 헤더 그대로 전체 교체한다.
4. 다른 시트는 그대로 둔다.
5. `매출.xlsx`와 `매출` 시트가 없으면 오류로 중단한다.
6. 정상 처리된 CSV만 선택한 폴더의 `completed`로 옮긴다. (폴더 없으면 생성, 같은 이름은 덮어씀)
7. 실패한 CSV는 선택한 csv 폴더에 남긴다.
